# 3D Scroll - Immersive Web Experiments

Experimental web layouts focusing on advanced 3D scrolling effects and horizontal stretching interactions.

## 🌟 Experiments
- **Horizontal Scroll**: Immersive side-scrolling navigation with depth effects.
- **Horizontally Stretch**: Dynamic layout stretching based on scroll/interaction velocity.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3 (Transforms/Transitions), Vanilla JavaScript.

## 📁 Key Files
- `horizontal scroll.html`: 3D horizontal scrolling prototype.
- `horizontally stretch.html`: Experimental stretching interaction logic.
