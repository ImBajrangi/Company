# Vrinda Bot - Intelligent Customer Assistant

A specialized chatbot interface designed to provide instant support and information for the Vrindopnishad ecosystem.

## 🌟 Features
- **Conversational UI**: Fluid, natural chat bubble interactions.
- **Embedded Integration**: Designed to live as a persistent widget on homepages.
- **Quick Actions**: Integrated buttons for common queries and service discovery.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript.

## 📁 Key Files
- `vrinda bot.html`: Main chatbot widget structure and logic.
