# Vrinda Chat - Devotional Conversation Interface

A minimal and elegant chat interface designed for community interaction and spiritual discussion.

## 🌟 Features
- **Modern UI**: Clean, minimal design with smooth animations.
- **Embedded Mode**: Can be easily integrated into other pages within the Vrindopnishad ecosystem.
- **Service Ready**: Designed to work with backend chat services or AI bots.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript.

## 📁 Key Files
- `vrindaChat.html`: The main chat interface file.
