# Vrindopnishad Apps Distribution

Central repository for modern Android applications developed for the Vrindopnishad ecosystem.

## 📦 Applications

### 1. Foody Vrinda App
- **Path**: `foodyVrindaApp/foodyVrinda.apk`
- **Description**: The mobile application for the Foody Vrinda cloud kitchen.
- **Platform**: Android.

### 2. Vrindopnishad / Sant Vaani App
- **Path**: `santVaani/vrindopnishad.apk`

- **Platform**: Android.

## 🚀 Installation
Download the APK files directly from this directory and install them on your Android device (ensure "Allow from unknown sources" is enabled).
