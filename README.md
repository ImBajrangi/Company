## 🤝 Contributing

We welcome contributions from the team! To ensure stability and security, we follow a strict branching and PR model.

**Please read the [Contributing Guide](CONTRIBUTING.md) before starting.**

### Professional Workflow Summary:
1.  **Repo Setup:** Use Blobless clones to save local storage.
2.  **Isolation:** Never work on `main`. Always create a feature branch.
3.  **Review:** All changes must go through a Pull Request and require approval from @ImBajrangi.
4.  **Quality:** Ensure code is clean and tested before pushing.
